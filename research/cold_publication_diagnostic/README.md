# Cold publication phase diagnostic

This endpoint-free diagnostic splits producer wait, frame metadata, buffer
publication, mutex acquisition, pixel copy and notification. Original main80
runtime sources, workload, absolute epoch, thresholds and archive inputs remain
unchanged. Only this separate executable overlays the copied instrumented core
and chain; the original main80 motion object and five static libraries are
explicit imports. The linker map must prove the core member replacement.

`build.ps1 -FrozenHead <clean-main-commit>` builds three translation units and
runs sixteen aggregate controls. Current source, exact copied source snapshot,
compiler environment, selected dependencies, imported objects, runtime copies,
and owned Native8 before/after closures are bound independently.

`run.ps1` creates a fresh diagnostic campaign for the original full 2560-attempt,
20 ms workload. Producer provenance and original full raw auditing are required.
All 2624 diagnostic slots are written after producer join in bounded metadata
segments. Extra phase clock reads never replace a business exception. Wait reads
are forwarded once with no extra per-poll clock read or OS call.

These measurements locate an interval; they do not prove OS causation or confer
Normal, AA, noise, ABBA, cost, device or live qualification. Instrumentation
overhead remains unmeasured. Historical raw and STOP results remain binding.
No ETW recording, emulator, device, Computer Use or new thread is involved.

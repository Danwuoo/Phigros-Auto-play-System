**Phigros 譜面裡「判定線能被設計成什麼組合／形式」**，其實可以把它看成「幾何結構 × 動態 × Note 配置」三層疊加。Phigros 的判定線本身可以有一條或多條，並且平移、旋轉、出現／消失；不同線也能各自承載 Note。

### 1. 幾何排列

常見或理論上很好做的組合包括：

| 類型 | 大致樣子 | 特點 |
|---|---|---|
| 單線 | `────` | 最基本 |
| 平行雙線 | `────`<br>`────` | 上下夾擊、雙軌 |
| 多平行線 | `────` × N | 多層軌道 |
| 垂直線 | `│` | Note 左右飛入 |
| 十字 | `─┼─` | 水平＋垂直兩條線 |
| X 型 | `╲ ╱` | 兩條斜線交叉 |
| 米字／放射狀 | `✳` | 多線共用中心 |
| V / Λ 型 | `╲╱` | Note 朝中心或向外 |
| Z / N 型 | 多段斜線 | 視覺導向明顯 |
| 方框 | `□` | 四條判定線包圍畫面 |
| 菱形 | `◇` | 方框旋轉 45° |
| 三角形 | `△` | 三線組合 |
| 多邊形 | 六角形等 | 大量判定線拼接 |
| 網格 | `#` | 橫線＋直線多組 |
| 星形 | `☆` | 多條線交叉排列 |

要注意的是，遊戲邏輯上它們通常還是**獨立的直判定線**；「方框、三角形、圓形」很多時候只是多條直線在畫面上拼成的視覺形狀。

---

### 2. 動態形式

真正讓 Phigros 看起來不像普通下落式音遊的部分，是判定線可以隨時間變化。

例如：

- **平移**：左右、上下、斜向移動
- **旋轉**：定點轉向、持續旋轉
- **平移＋旋轉**：像掃描器、鐘擺、旋轉木馬
- **瞬移**：快速從 A 點換到 B 點
- **震動／抖動**：短距離快速往返
- **往復運動**：左右擺動、上下浮動
- **環繞運動**：多條線配合做出繞中心旋轉的錯覺
- **淡入／淡出**：透明度變化，甚至完全不可見
- **高速切換角度**：水平 → 斜線 → 垂直
- **多線聚合／分裂**：多條線看似從一點散開或重新合併

官方遊戲描述與相關資料都提到判定線能改變位置、朝向、透明度與旋轉等，而這些變化是譜師預先設定好的，不是隨機產生。

### 3. 多線之間的組合

這裡的玩法空間更大。例如：

**鏡像雙線**

```text
\       /
 \     /
  \   /
```

兩邊同步或反向移動，Note 從兩側向中間進入。

**夾擊型**

```text
──────  ↓
  Note
──────  ↑
```

Note 同時從上下兩側接近兩條判定線。

**十字旋轉**

```text
   │
───┼───
   │
```

整個十字繞中心轉動，Note 的視覺方向也跟著改變。

**風車型**

```text
 \ | /
-- + --
 / | \
```

多條線以共同中心旋轉，可以做出很強的「旋轉軌道」效果。

**框體型**

```text
┌────────┐
│        │
│        │
└────────┘
```

四條線各承擔一個方向的 Note，甚至可以讓整個框旋轉、縮放或拆開。

**多中心型**

```text
  +         +
 /|\       /|\
```

畫面左右各有一組獨立判定線，像同時玩兩個譜面。

### 4. 判定線 × Note 的形式

這一點其實比判定線本身更重要。

判定線可以做到：

**Note 在線的一側**

```text
 ↓ ↓ ↓
───────
```

最普通。

**Note 在線的兩側**

```text
 ↑ ↑ ↑
───────
 ↓ ↓ ↓
```

也就是俗稱的上下／雙面配置。

**左右進入**

```text
→ → │ ← ←
```

把判定線轉 90°。

**斜向進入**

```text
 ↘
   ╲
     ↘
```

判定線傾斜後，整套 Note 的視覺方向就會完全改變。

**線追 Note**

看起來不是 Note 朝判定線飛，而是**判定線自己移過去接 Note**。

**Note 充當判定線提示**

甚至可以把真正的判定線隱藏，只留下 Note 或其他視覺元素暗示判定位置。這種做法在實際譜面中存在。

---

### 5. 更複雜的「套路」

把上述元素直接排列組合，例如：

1. **平行雙線 + 反向移動** → 剪刀／夾擊
2. **十字 + 持續旋轉** → 旋轉十字
3. **四線 + 方框 + 旋轉** → 旋轉房間
4. **多條放射線 + 同心旋轉** → 風車／雷達
5. **兩條斜線 + 交叉移動** → X 型剪刀
6. **隱形線 + Note 定位** → 無線判定
7. **多線重合 → 突然分離** → 分裂效果
8. **多線分散 → 突然重合** → 聚合效果
9. **父線旋轉 + 子線自身運動** → 公轉＋自轉
10. **判定線移動 + Note 逆向運動** → 強烈視覺錯位

所以如果純粹從「能設計出什麼」來看，可以概括成：

**單線 / 雙線 / 多線  
× 平行 / 交叉 / 放射 / 多邊形  
× 靜止 / 平移 / 旋轉 / 往復 / 聚散  
× 顯示 / 半透明 / 隱藏  
× 單側 Note / 雙側 Note / 多方向 Note  
× 同步 / 鏡像 / 獨立運動 / 父子聯動。**

這樣組合下去，實際上可以做出非常多種判定線結構。
